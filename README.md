# 🧠 Alzheimer's Disease RAG Research Assistant

RAG-система для анализа научной литературы и поиска потенциальных терапевтических мишеней при болезни Альцгеймера.

## Основные возможности

- **Сбор данных**: Глубокий парсинг статей с разделением на секции (Abstract, Introduction, Conclusion).
- **Умный поиск (RAG)**: Двухэтапная система (Retrieval + Reranking) на базе специализированных медицинских моделей.
- **Интерактивный UI**: Streamlit-интерфейс для работы с результатами в реальном времени.
- **Оценка качества**: Метрики MRR и Hit Rate для контроля точности поиска.

## Технологический стек и Архитектура

### 1. Сбор и подготовка данных (Data Ingestion)
- **Парсинг**: Использование `pubmed-parser`. Система фильтрует статьи, оставляя только те, где удалось извлечь и введение, и заключение, что гарантирует полноту контекста.
- **Smart Chunking**: Разразботан алгоритм скользящего окна (`sliding_token_windows`), который автоматически выравнивает границы чанков по точкам и концам предложений, не разрывая смысловые блоки.
- **Источники**: Интеграция с Europe PMC REST API и NCBI E-utilities.

### 2. Векторизация и Embeddings
Используются доменно-специфичные модели **MedCPT** (768-dim), обученные на миллионах запросов к PubMed:
- **Bi-Encoder**: `ncbi/MedCPT-Query-Encoder` и `ncbi/MedCPT-Article-Encoder` для быстрого поиска.
- **Параллелизм**: Реализована асинхронная обработка векторов с использованием `asyncio.Semaphore(20)` для эффективного взаимодействия с HuggingFace Inference API.

### 3. Двухэтапная Retrieval-логика
Система использует гибридную схему поиска для достижения максимальной релевантности:
1. **Первичный поиск (Vector Search)**: ChromaDB (алгоритм HNSW + Косинусное сходство). Отбирает 50 потенциальных кандидатов.
2. **Переранжирование (Reranking)**: Модель `ncbi/MedCPT-Cross-Encoder` оценивает каждую пару "вопрос-кандидат" на глубоком семантическом уровне.
3. **Результат**: Только топ-5 самых релевантных фрагментов передаются в LLM.

### 4. Генерация (Generation)
- **LLM**: `meta-llama/Meta-Llama-3-8B-Instruct`.
- **Метод**: RAG с четкой привязкой к источникам (PMID), что исключает галлюцинации и позволяет проверить каждый факт.

## Установка и запуск

1. **Клонирование**:
   ```bash
   git clone https://github.com/VasilijEpishkin/alzheimer-rag-agent.git
   cd alzheimer-rag-agent
   ```

2. **Зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запуск**:
   - **UI**: `streamlit run src/app.py`
   - **Индексация**: `python src/rag/ingest.py`
