# Code Review: Alzheimer's RAG Agent

## Архитектура системы

Проект представляет собой классическую RAG-систему (Retrieval-Augmented Generation), предназначенную для анализа научной литературы по болезни Альцгеймера.

### Сильные стороны:
1.  **Модульность**: Четкое разделение на сбор данных (`collector.py`), индексацию (`ingest.py`) и инференс (`retriever.py`, `generator.py`).
2.  **Асинхронность**: Использование `asyncio` для сбора данных из PubMed, что значительно ускоряет процесс.
3.  **Гибкость**: Настройка параметров через `config.py` и переменные окружения.
4.  **Комплексность**: Наличие не только кода системы, но и скриптов оценки (`evaluation/`).
