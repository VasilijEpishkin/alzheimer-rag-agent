# Метрики и Оценка (RAG Evaluation)

Для оценки качества работы системы используются специализированные метрики, покрывающие оба этапа RAG-конвейера: поиск (Retrieval) и генерацию (Generation).

## 1. Метрики Поиска (Retrieval Metrics)

Эти метрики оценивают, насколько релевантные документы находит система по заданному запросу.

*   **Hit Rate (Recall@K)**: Показывает, попал ли хотя бы один релевантный документ в топ-K результатов.
*   **Mean Reciprocal Rank (MRR)**: Оценивает позицию первого релевантного документа. Чем выше документ, тем выше оценка (1/rank).
*   **NDCG (Normalized Discounted Cumulative Gain)**: Учитывает порядок выдачи и "ценность" позиции.

## 2. Метрики Генерации (Generation Metrics)

Оценка качества ответа LLM на основе найденных контекстов. Используется подход **LLM-as-a-Judge** (с помощью `RAGAS` или кастомных промптов).

*   **Faithfulness (Верность)**: Насколько ответ подтверждается предоставленным контекстом (отсутствие галлюцинаций).
*   **Answer Relevance (Релевантность ответа)**: Насколько ответ соответствует вопросу.
*   **Context Precision**: Насколько найденные контексты действительно полезны для ответа.
